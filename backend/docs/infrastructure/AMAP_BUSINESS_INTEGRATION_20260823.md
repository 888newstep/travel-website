# 高德业务能力接入记录（2026-08-23）

## 1. 接入范围

当前项目使用高德 Web Service API，已接入以下业务闭环：

- 景点关键字搜索：作为独立的外部地点候选，不写入本地景点表，不附加本地评分和点评。
- 景点周边设施：餐饮、停车场、公共厕所、公交/地铁四类白名单，默认半径 1 公里。
- 景点实时天气：通过景点坐标完成逆地理编码，再查询城市实时天气。
- 路线驾车路况：按路线内相邻景点聚合真实距离、时长和 `tmcs` 拥堵状态。

项目继续保留本地景点搜索和本地周边景点推荐，高德 POI 不会被静默持久化为本地业务对象。

## 2. 对外接口

| 接口 | 说明 |
|---|---|
| `GET /api/attractions/external-search?keyword=故宫&city=北京&page=1` | 高德地点候选，页码限制 1–20 |
| `GET /api/attractions/{id}/nearby-facilities?category=parking&radiusMeters=1000` | 周边设施，半径限制 100–5000 米 |
| `GET /api/attractions/{id}/weather` | 景点坐标对应的实时天气 |
| `GET /api/routes/{id}/traffic` | 路线相邻景点的驾车距离、时长和分段路况 |

周边设施 `category` 只接受 `restaurant`、`parking`、`restroom`、`transit`，调用方不能透传任意高德类型码。

## 3. 配额保护

- 地点搜索缓存 24 小时，天气缓存 30 分钟，驾车路线缓存 1 小时，路线聚合缓存 5 分钟。
- 高德客户端配置进程内平滑限流，默认 `AMAP_MAX_QPS=3`。
- 限流等待默认最多 `AMAP_RATE_LIMIT_MAX_WAIT_MS=1000`，排队溢出时返回不可用状态，不伪造数据。
- 现有并发舱壁继续限制同步外部调用并发数。
- 当前部署为单实例服务时，进程内限流满足配额保护；扩展为多实例后应将 3 QPS 限流迁移为 Redis/Lua 全局令牌桶。

## 5. JS 地图边界

当前凭据是服务端 Web Service Key，只能保存在后端环境变量中。浏览器地图初始化需要单独申请 JS API Key 和安全密钥；在提供这两项配置前，前端不会嵌入地图，也不会把服务端 Key 写入 `VITE_*` 或构建产物。
