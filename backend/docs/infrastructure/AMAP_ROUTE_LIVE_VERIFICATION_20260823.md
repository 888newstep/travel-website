# 高德路线规划真实外呼验收

## 1. 验收范围

- 使用项目本地 MySQL 中的真实路线与景点坐标。
- 调用高德 Web 服务驾车路线规划接口，不使用本地桩或固定响应。
- 两点场景验证距离、时长和 `extensions=all` 返回的 `tmcs` 实时路况分段。
- 多点场景验证途经点、总距离、总时长、过路费和导航步骤。
- API Key 仅通过当前进程的 `AMAP_API_KEY` 注入，不写入仓库、摘要或日志。

步行和公交方法当前没有接入项目 Controller 或业务服务，本次不将其计入已交付能力。

## 2. 执行方式

```powershell
$env:AMAP_API_KEY = '<高德 Web 服务 Key>'
.\ops\amap\run-amap-route-live-test.ps1
```

脚本从 MySQL 自动选择一条两景点路线和一条至少三景点路线，执行 `AMapRouteLiveIT`，并对输出中的高德 Key 和数据库密码进行脱敏。

脱敏证据：

- `run-logs/amap/20260823-175126/run-summary.json`
- `run-logs/amap/20260823-175126/maven-output.log`

`target` 下的 Surefire 报告会被后续 `clean` 删除，因此持久证据以 `run-logs` 中的摘要和脱敏 Maven 输出为准。

## 4. 结论与边界

- 高德 Key 可用于当前项目的真实驾车路线规划。
- 两点实时交通和多点途经点规划均返回有效结果，项目不再处于“仅本地桩验证”状态。
- 本次结果证明接口与业务数据可用，不代表高德配额、长期可用性或生产容量承诺。
- 距离与导航结构相对稳定，实时交通时长会随高德路况数据变化，不应写成固定业务常量。
- Key、数据库密码和其他凭据不得出现在 Git、截图、答辩材料或公开日志中。
