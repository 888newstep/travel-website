# 统一验收指标矩阵

## 1. 口径

- HTTP/JMeter 容量场景记录样本数、平均响应、P95、P99、吞吐、错误率和最终数据库事实。
- RabbitMQ 场景记录消息数、端到端消费耗时、消息吞吐、落库数和丢失数；HTTP 响应指标不适用。
- Redis 故障场景记录故障状态码、恢复结果和数据库不变量；吞吐与百分位不用于判断故障保护是否正确。
- Redis 命中率只适用于缓存读取压测。本轮场景验证写一致性、故障保护或消息消费，均不以缓存命中率作为验收指标。
- “最终数据库事实”表示业务不变量，不等同于 SQL 执行次数，避免把事务内部实现细节误报为业务写入量。

## 3. 结论

现有证据可以证明并发正确性、最终数据库状态、消息可靠性和 Redis 故障保护，但不能据此宣称生产容量上限。后续若要展示 Redis 命中率，应单独建立稳定热点读、冷读和缓存击穿场景，并从统一 Micrometer 指标采集命中与未命中次数。
